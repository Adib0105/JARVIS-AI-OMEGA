## Safety defaults

```env
SELF_DEVELOPMENT_ENABLED=true
PRODUCTION_SELF_MODIFICATION=false
REQUIRE_APPROVAL_FOR_PRODUCTION=true
AUTO_ROLLBACK_ENABLED=false
```

The target is controlled improvement:

```text
Discover → Propose → Sandbox → Build → Test → Security/Evaluation → Diff → Approval
→ Controlled Release → Post-test → Rollback if required
```

A green automated suite certifies software state; it does **not** pretend that real microphone hardware, live providers, OAuth accounts, desktop UI behavior or an Inno Setup installation were physically tested. `self_check_v75.py` reports those live gates as pending until real evidence exists.

The audit integrity chain is **tamper-evident**, not magic tamper-proof storage: a fully privileged attacker who can rewrite the complete local database can also rewrite local integrity metadata. OS/database access control remains part of the security boundary.

It is intentionally **not** unrestricted autonomous production rewriting.
