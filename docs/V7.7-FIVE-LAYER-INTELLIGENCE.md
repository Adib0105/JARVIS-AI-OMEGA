# V7.7 five-layer intelligence

JARVIS V7.7 turns the requested AI → Machine Learning → Deep Learning → Generative AI → LLM order into one real routing pipeline. The layers are observable responsibilities inside a single safe runtime. They are not five unrelated models, and they do not imply a human brain or guaranteed correctness.

## Runtime order

| Order | Layer | Runtime responsibility |
|---:|---|---|
| 1 | Artificial Intelligence | Uses deterministic intent rules, current context, capability state, tool policy and the existing agent runtime to establish a safe base route. |
| 2 | Machine Learning | Runs a local multinomial intent classifier and adapts to successful operator vocabulary across FAST, SMART, CODING, PLANNING, REVIEW and SUMMARY routes. |
| 3 | Deep Learning | Uses the configured neural language/vision provider. An embedding-based semantic routing signal is available only when the operator explicitly enables and configures it. |
| 4 | Generative AI | Maps the decision to conversational, deep-reasoning, code, plan, review, summary, multimodal or local generation behavior. |
| 5 | Large Language Model | Resolves the final model identifier through the existing provider-neutral FAST / SMART / specialist routing configuration. |

The final trace contains the route, model, confidence, generation mode, tool strategy and status of all five layers. It is included in runtime instructions and available through `JarvisOmega.intelligence_status()` and the Command Center **INTELLIGENCE** tab.

## Decision safety

- An explicit VISION, CODING, PLANNING, REVIEW, SUMMARY or LOCAL route is stable; ML cannot downgrade it.
- Local ML may upgrade a generic route only above `ADAPTIVE_ML_MIN_CONFIDENCE`.
- The optional neural semantic signal may influence a generic route only when it agrees with local ML and clears `NEURAL_ROUTING_MIN_CONFIDENCE`.
- A semantic endpoint failure is contained and deterministic routing continues.
- Secret-like request text never reaches the optional semantic embedding router.
- Routing selects behavior and models only. It cannot bypass capability permissions, approval prompts, audit recording, tool allowlists, verification or mission limits.
- Missing generation credentials produce a truthful degraded layer status; local routing itself remains available.

## Private adaptive ML

The adaptive classifier is deliberately small and local:

- ships with English, Hindi and Hinglish seed vocabulary;
- learns only after a successful chat result;
- rejects secret-like prompts and oversized samples;
- persists only BLAKE2 token fingerprints and bounded counts in the active user's data directory;
- never writes the original prompt or readable learned tokens to its model file;
- caps observations and decays old counts instead of growing without limit;
- caps retained feature fingerprints per route so disk and prediction work stay bounded;
- treats a missing or corrupt learning file as an empty model and keeps routing available;
- can be reset without deleting chats, memory, accounts or settings.

Chat history remains governed by the existing JARVIS memory settings. The no-raw-prompt guarantee here applies specifically to the adaptive route-model file and intelligence telemetry.

Token fingerprints are data minimization, not encryption: a determined attacker with local file access may still guess common tokens. Protect the Windows account and profile directory, and never enter secrets into prompts unnecessarily.

## Optional neural semantic routing

Neural semantic routing is off by default because an external embedding endpoint receives the request text and may add network latency or cost. Enabling it requires all of the following:

```dotenv
ENABLE_NEURAL_SEMANTIC_ROUTING=true
EMBEDDING_BASE_URL=http://127.0.0.1:11434/v1
EMBEDDING_MODEL=your-embedding-model
EMBEDDING_API_KEY=
```

Use a local endpoint when request text must remain on the computer. If a remote endpoint is configured, its privacy and retention terms apply.

## Configuration

| Setting | Default | Purpose |
|---|---:|---|
| `ENABLE_FIVE_LAYER_INTELLIGENCE` | `true` | Enables the ordered stack; disabling it retains deterministic legacy routing. |
| `ENABLE_ADAPTIVE_ML_ROUTING` | `true` | Enables private local adaptive classification. |
| `ADAPTIVE_ML_MIN_CONFIDENCE` | `0.72` | Minimum local ML confidence for upgrading a generic route. |
| `ADAPTIVE_ML_MAX_OBSERVATIONS` | `5000` | Bounded learning history before count decay. |
| `ENABLE_NEURAL_SEMANTIC_ROUTING` | `false` | Enables the explicitly configured embedding route signal. |
| `NEURAL_ROUTING_MIN_CONFIDENCE` | `0.76` | Minimum neural confidence, in addition to local-ML agreement. |

The desktop Settings dialog exposes these controls. Numeric validation fails closed outside the documented ranges.

## Evidence and remaining release boundary

The regression suite covers exact layer ordering, specialist-route stability, adaptive vocabulary, no raw-prompt persistence, secret rejection, corrupt-file recovery, reset isolation, configuration bounds, capability/observability integration and neural consensus.

Automated tests cannot prove microphone hardware behavior, tray persistence, browser focus retention, wake-word accuracy, Windows installation/upgrade behavior or Microsoft Defender results on the operator's PC. Those remain real-Windows release gates in [the V7.6 launch pack](V7.6-LAUNCH-PACK.md). A hosted subscription product also still requires a reviewed cloud identity, billing, recovery, licensing, privacy and operations backend.
