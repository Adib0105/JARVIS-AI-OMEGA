# V7.6 launch pack

This update targets the repeated Windows wake/background failure and adds a
local account foundation plus an exact 20-action Windows control pack.  It does
not claim that a public subscription service exists; billing, remote account
recovery, license enforcement and server operations need a separate backend.

## Siri-style background flow

1. The listener loads the selected Vosk model and opens the real microphone.
2. Only then does the UI report **Background microphone READY**.
3. “Wake up Jarvis” produces “Yes boss, kya chahiye?”.
4. JARVIS releases the hotword stream, waits for its own speech to finish, then
   records one command with local VAD and the same offline Vosk model.
5. The hotword stream is reopened and readiness-checked before the command is
   sent to the assistant.
6. The main window stays hidden unless **Bring the JARVIS window forward** is
   explicitly enabled.
7. A disconnected device keeps the tray process alive and retries after
   3, 10, 30, 60 and then 120 seconds.

The PC must remain awake and signed in. Windows microphone privacy must allow
desktop applications. A real microphone cannot be validated by Linux tests.

## Local accounts

- login ID plus password;
- per-user display name used by Friday and the header;
- salted PBKDF2-SHA256 password digest (no stored plaintext password);
- 30-second temporary lock after five failed attempts;
- remembered random session token for sign-in background startup;
- per-profile database, Google token, preferences and exports;
- first profile can retain an existing legacy data directory;
- **Sign out / switch user** in the desktop header.

The remembered token is a local convenience credential protected by the
Windows user profile/file permissions. This is not cloud identity, payment,
subscription enforcement or cross-device sync.

## Twenty Windows Power Pack actions

All actions use one exact allowlisted `windows_control` tool. They cannot inject
an arbitrary executable or shell command. The HIGH-risk capability gate and
audit remain active.

1. Volume up
2. Volume down
3. Mute/unmute toggle
4. Media play/pause
5. Next media track
6. Previous media track
7. Show desktop
8. Switch window
9. Minimize current window
10. Maximize current window
11. Close current window
12. Create virtual desktop
13. Move to next virtual desktop
14. Move to previous virtual desktop
15. Lock the PC
16. Open Wi-Fi settings
17. Open Bluetooth settings
18. Open display settings
19. Open sound settings
20. Open installed-app settings

English and common Hinglish exact phrases are routed locally without an AI
round trip. Consequential actions still require the configured permission.
