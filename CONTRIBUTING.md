# Contributing

Thanks for contributing to JARVIS AI OMEGA.

1. Fork the repository.
2. Create a focused feature branch.
3. Keep secrets out of commits.
4. Add or update tests for behavior changes.
5. Run `python -m unittest discover -s tests -v`.
6. Open a pull request explaining what changed and why.

Please keep new local-computer tools narrow, auditable, and permission-aware. Do not add arbitrary shell execution or credential-access features.
