# Changelog

## 5.0.0

Major multimodal desktop upgrade.

- Added multi-image upload in the desktop app.
- Added Windows clipboard image paste support.
- Added local image preview, validation, dimensions, and size display.
- Added in-memory resize/compression before provider upload.
- Added terminal `/image` command.
- Unified uploaded-image and Screen Vision processing.
- Added configurable AI/vision timeouts and SDK retries.
- Added clearer multimodal/provider error handling.
- Upgraded desktop controls with image help, file learning, chat export, status, and one-click launcher.
- Kept typed input + spoken neural Hindi/Hinglish output; microphone input remains disabled.
- Bumped package/runtime version to 5.0.0.
- Added V5 image attachment tests and documentation.
