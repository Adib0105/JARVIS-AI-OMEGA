# Changelog

## 6.0.0

Major ARC desktop-agent release.

- Rebuilt desktop UI as an animated futuristic ARC/HUD dashboard.
- Added idle/thinking/listening/speaking/error reactor animation states.
- Added speaking/listening waveform animation tied to the TTS state.
- Added permanent `OPERATOR: ADIB AZAM` identity in the main interface.
- Added live CPU, RAM, disk, battery, and process telemetry.
- Added Planner → Executor → Reviewer Mission mode.
- Added optional push-to-talk microphone input.
- Added optional runtime “Hey Jarvis” wake-word listener.
- Added PDF, DOCX, XLSX/XLSM, CSV, TXT and Markdown document intelligence.
- Added searchable prior chat history.
- Added local todos and reminders with spoken desktop reminder alerts.
- Added approval-gated Google/Bing/YouTube/GitHub browser search launching.
- Expanded allowlisted Windows app launching.
- Added approval-gated keyboard typing, hotkeys, key presses and screen clicks.
- Added guarded coding workspace tree inspection.
- Added approval-gated safe text/code file writes with automatic backups.
- Added an allowlisted Python unittest project runner; no arbitrary shell tool was added.
- Added V6 configuration, Windows optional dependency file, setup diagnostics and launchers.
- Added V6 productivity, document, mission-planner and coding-workspace tests.
- Kept V5 multi-image upload, clipboard image, screen vision, web/news tools, memory, knowledge and neural Hindi/Hinglish voice.
- Bumped runtime/package version to 6.0.0.
